# Steam Local Server Manager — Atualizações

Este repositório publica somente os instaladores assinados e o manifesto de atualização do aplicativo. O código-fonte permanece no repositório privado `steam-local-server-manager`.

## Instalação inicial

Baixe o instalador Windows x64 na página [Releases](https://github.com/dehquadros/steam-local-server-manager-updates/releases/latest). A versão 0.1.1 inclui o atualizador. Quem usa 0.1.0 precisa instalar essa versão manualmente uma vez; depois poderá verificar e aplicar versões futuras pelo botão dentro do aplicativo.

Os pacotes de atualização são assinados. O aplicativo confere a assinatura antes de instalar.

## Steam Deck

A versão Flatpak do Steam Deck atualiza pelo Discover/Flathub. Este atualizador próprio é usado pelo instalador Windows.
